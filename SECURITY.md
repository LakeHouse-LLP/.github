# Security Policy

## Supported versions

Security fixes apply to the default branch (`main`) of each active LakeHouse-LLP repository. Disposable `sandbox-*` and `legacy-*` repos are out of scope unless Sen says otherwise.

## Reporting a vulnerability

Use **GitHub private vulnerability reporting** for this organization:

1. Open the repository on GitHub.
2. Go to **Security → Advisories → Report a vulnerability** (or **Report a vulnerability** on the Security tab).
3. Include impact, reproduction steps, and any suggested fix.

Do **not** open a public issue for security reports. Do **not** attach secrets, credentials, or client data to public channels.

If private vulnerability reporting is not yet enabled on a repo, contact the org owner (Sen) privately via GitHub. Sen enables private vulnerability reporting in the GitHub UI (see [docs/sen-only-github-settings.md](docs/sen-only-github-settings.md)).

## Response

Sen will acknowledge reports and coordinate fixes. Prefer coordinated disclosure after a fix is available on `main`.
